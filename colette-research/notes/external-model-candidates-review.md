## admission boundary

a provider/model word plus network code is not enough. admission requires inference-specific endpoint or protocol evidence, an inference-shaped request body, and an outbound invocation in the same defensible artifact bundle.

a response handler is not a response. a direct child is not a model response unless its content itself is provider-returned model material. none passed that test.
