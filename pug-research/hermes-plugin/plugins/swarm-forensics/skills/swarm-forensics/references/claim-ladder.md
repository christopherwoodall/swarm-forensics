# Claim ladder (bundled with the plugin)

Interpret every hit at the lowest supported rung. Never operator identity.

- **L1 artifact:** a single URL carries agent-shaped grammar. Some agent
  system touched public infrastructure. Nothing more.
- **L2 burst:** cadence + digest concentration. Automated, repeated
  retrieval — a running task, not a curious click.
- **L3 task:** a selective filter or param shape names the data being
  extracted. The task family is now observable.
- **L4 toolkit:** relay-stack + nonce-grammar + construction artifacts
  co-occur. Shared launcher/toolkit across incidents — provider-level.
- **L5 operation:** same task + same window + same toolkit across venues.
  One operation. The highest claim this framework supports.
- **Never:** operator identity. No rule here reaches a human.
